# قبان الغد — Windows bridge 0.9

تطبيق .NET Framework 4.5.1+ يفتح منفذ الميزان مرة واحدة، ويرسل أحدث قراءة مستقرة كل ثانية إلى النظام الأساسي والمرتجعات عبر قناتين مستقلتين. الإعدادات السابقة محفوظة، ولا يوجد طابور أوزان قديمة. الطلب والمهلة والإلغاء والرمز وحالة الرد مستقلة لكل وجهة.

## البناء

افتح Build-and-Run.cmd على Windows. يستخدم مترجم .NET Framework المحلي، ويشغّل اختبارات البروتوكول قبل بناء التطبيق بأيقونته.

- Bridge.Tests.exe --self-test: البروتوكول والحداثة والجدولة والردود.
- Bridge.Tests.exe --integration-test: نقل HTTP محلي على HttpListener؛ قد يتطلب URL ACL على Windows.
- Bridge.Tests.exe --dual-test: خادمان TCP محليان لاختبار استقلال الوجهتين، وتعطل إحداهما، وعدم اختلاط الرموز أو الأوزان، وتشفير الرموز للحساب الحالي.

الاختبارات لا تستخدم خوادم الشركة أو كلمات مرورها. يوجد تحقق Windows في .github/workflows/scale-integration.yml.

## الإعدادات

احتفظ بعنوان النظام الأساسي ورقم الشركة. عنوان المرتجعات الافتراضي https://qaban-113.pages.dev/api/scale/weight. أدخل SCALE_API_TOKEN محليًا في «رمز المرتجعات» ثم حفظ. كلمة مرور الموقع ليست رمز API.

تُشفّر الرموز باستخدام DPAPI/CurrentUser، ويجب إعادة إدخالها عند تغيير حساب Windows أو الجهاز. لا ترفع settings.json أو ملفات الرموز إلى Git.

التفاصيل الكاملة في [دليل الربط](../../artifacts/ghad-concrete/SCALE_INTEGRATION.md). «تم الإرسال» يعني اكتمال كتابة الطلب، ورد الخادم منفصل ويظهر HTTP 500 دون إخفائه.

يدعم Bootstrap.cs استيراد ملف تهيئة خاص اختياري Returns.setup.json لمرة واحدة؛ لا ترفعه إلى Git. تشفر بياناته محليًا ويحذف بعد حفظها. النسخة المنشورة من المصدر لا تحتوي رمزًا إنتاجيًا.
