description: The concrete company's chosen sign-in model for the operations app.
---

For الغد للباطون الجاهز, use one shared admin account with an in-app login. Do not switch to Cloudflare Access or per-employee accounts unless the user asks.

**Why:** The user explicitly chose the simplest shared account and asked for a login screen inside the app.

**How to apply:** Keep the admin username and password configured in Cloudflare Pages settings; never ask the user to send credential values in chat.
